# Lamiaa Portfolio — new version

## Files
- `index.html`: page content
- `style.css`: responsive design and styling
- `script.js`: mobile navigation, current year, and scroll reveal animations

## Run locally
Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Publish on GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and all six project image files to the same repository folder.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select your branch (usually `main`) and root folder `/`, then save.
4. Wait for GitHub Pages to publish the new version.
